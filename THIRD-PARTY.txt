Third-party libraries shipped with DeckForever
==============================================

DeckForever itself is MIT licensed (see LICENSE.txt). It embeds the libraries
below unchanged except where a file says "DeckUI: Mists" (small patches of
DeckUI's, carried over as they are) or "DeckForever" (two lines in
LibActionButton-1.0.lua that let it run on World of Warcraft: Forever).
Each is used under its own licence, all
of which are permissive and compatible with MIT. The licence names are the
ones the libraries state themselves, in their own .toc files or file headers.

The BSD licences require the copyright notice to be kept when the software
is redistributed. Those notices are in the library files themselves, and
this file is not a substitute for them - do not strip the headers when
updating a library.

Some libraries ship their own nested copies of LibStub and
CallbackHandler-1.0. DeckForever does not load those; DeckForever_Bars.toc
loads one copy of each, in this order: LibStub, CallbackHandler-1.0,
LibButtonGlow-1.0, LibActionButton-1.0. package.ps1 leaves the unused
copies out of the release archive.
